# geometric_lib
## Описание
`geometric_lib` — библиотека для вычисления площади и периметра простых геометрических фигур: круга, прямоугольника, квадрата и треугольника.

## Circle
```python
area(r)
```  
```python
perimeter(r)
```  
Функция area() возвращает площадь **круга** по формуле **S = πr²**.  
функция perimeter() возвращает периметер **круга** по форумуле **P = 2πr**.

Параметры:
- **r** - радиус круга (десятичное число).

Возвращаемое значение:
- Десятичное число, посчитанное по формуле в зависимости от вызываемой функции

Примечение:
- π = 3.141592653589793

Пример:
```
import math

def area(r):
    return math.pi * r * r


def perimeter(r):
    return 2 * math.pi * r

print(area(6))
perimeter(10)
```

Результат:
```
113.09733552923255
62.83185307179586
```



## Rectangle
В модуле `Rectangle` заложены функции для вычисления площади и периметра **прямоугольника**. Здесь функции `area()` и `perimeter()` принимают на вход ровно два аргумента: a — длина, b — ширина (a и b — десятичные числа).

Используемые формулы:
- **S = ab** - вычисление площади
- **P = 2a + 2b** - вычисление периметра  

Команды для входа в интерактивный режим:
* `python -i rectangle.py`  
* `python3 -i rectangle.py`  

Примеры вызова функций:
* Ввод: `area(3, 10)` --> Вывод: `30`
* Ввод: `perimeter(4, 7)` --> Вывод: `22`

Для выхода из интерактивного режима воспользуйтесь командой `exit`.

## Square
В модуле `Square` заложены функции для вычисления площади и периметра **квадрата**. Здесь функции `area()` и `perimeter()` принимают на вход только один аргумента a — длина стороны (десятичное число).

Используемые формулы:
- **S = a²** - вычисление площади
- **P = 4a** - вычисление периметра  

Команды для входа в интерактивный режим:
* `python -i square.py`  
* `python3 -i square.py`  

Примеры вызова функций:
* Ввод: `area(6)` --> Вывод: `36`
* Ввод: `perimeter(5)` --> Вывод: `20`

Для выхода из интерактивного режима воспользуйтесь командой `exit`.

## Triangle
В модуле `Triangle` заложены функции для вычисления площади и периметра **треугольника**. Функции `area()` принимает на вход ровно два аргумента: a — длина основания, h — высота, проведённая к основанию (a, h - десятичные числа). Функция `perimeter()` принимает на вход ровно три аргумента: a, b и c — длины сторон (a, b и c — десятичные числа).

Используемые формулы:
- **S = ah / 2** - вычисление площади
- **P = P = a + b + c** - вычисление периметра  

Команды для входа в интерактивный режим:
* `python -i triangle.py`  
* `python3 -i triangle.py`  

Примеры вызова функций:
* Ввод: `area(4, 7)` --> Вывод: `14.0`
* Ввод: `perimeter(5, 7, 9)` --> Вывод: `21`

Для выхода из интерактивного режима воспользуйтесь командой `exit`.
