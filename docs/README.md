# geometric_lib
## Описание
'geometric_lib' - библиотека для вычисления площади и периметра геометрических фигур: круга, прямоугольника, квадрата и треугольника.


# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²
- Triangle: S = ah / 2

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
- Triangle: P = a + b + c
