# geometric_lib
## Описание
`geometric_lib` — библиотека для вычисления площади и периметра простых геометрических фигур: круга, прямоугольника, квадрата и треугольника.

## Circle
Данный модуль вычисляет площадь и переметер **круга**.
```python
import math

def area(r):
    return math.pi * r * r


def perimeter(r):
    return 2 * math.pi * r
```

### Area Circle
```python
area(r)
```  
Функция возвращает площадь **круга** по формуле **S = πr²**.  

Параметры:
- **r** - радиус круга (десятичное число).

Возвращаемое значение:
- Десятичное число, посчитанное по формуле **S = πr²**.

Примечение:
- π = 3.141592653589793.

Пример:
```python
print(area(6))
```

Результат:
```
113.09733552923255
```

### Perimeter Circle
```python
perimeter(r)
```  
Функция возвращает периметер **круга** по формуле **S = 2πr**.  

Параметры:
- **r** - радиус круга (десятичное число).

Возвращаемое значение:
- Десятичное число, посчитанное по формуле **S = 2πr**.

Примечение:
- π = 3.141592653589793.

Пример:
```python
print(perimeter(10))
```

Результат:
```
62.83185307179586
```



## Rectangle
Данный модуль вычисляет площадь и переметер **прямоугольника**.
```python
def area(a, b):
    return a * b 


def perimeter(a, b):
    return (a + b) * 2
```

### Area Rectangle
```python
area(r)
```  
Функция возвращает площадь **прямоугольника** по формуле **S = ab**.  

Параметры:
- **a** - длина квадрата (десятичное число).
- **b** - ширина квадрата (десятичное число).


Возвращаемое значение:
- Десятичное число, посчитанное по формуле **S = ab**.


Пример:
```python
print(area(3, 10))
```

Результат:
```
30
```

### Perimeter Circle
```python
perimeter(r)
```  
Функция возвращает периметер **прямоугольника** по формуле **S = 2a + 2b**.  

Параметры:
- **a** - длина квадрата (десятичное число).
- **b** - ширина квадрата (десятичное число).

Возвращаемое значение:
- Десятичное число, посчитанное по формуле **S = 2a + 2b**.

Пример:
```python
print(perimeter(4, 7))
```

Результат:
```
22
```


## Square
```python
area(a)
```  
```python
perimeter(a)
```  
Функция area() возвращает площадь **квадрата** по формуле **S = a²**.  
функция perimeter() возвращает периметер **квадрата** по форумуле **P = 4a**.

Параметры:
- **a** - длина стороны квадрата (десятичное число).

Возвращаемое значение:
- Десятичное число, посчитанное по формуле в зависимости от вызываемой функции.

Пример:
```python
def area(a):
    return a * a


def perimeter(a):
    return 4 * a

print(area(6))
print(perimeter(5))
```

Результат:
```
36
20
```

## Triangle
```python
area(a, h)
```  
```python
perimeter(a, b, c)
```  
Функция area() возвращает площадь **квадрата** по формуле **S = ah / 2**.  
функция perimeter() возвращает периметер **квадрата** по форумуле **P = a + b + c**.

Параметры:
- **a, b, c** - длины сторон треугольника (десятичные числа).
- **h** - длина высоты, проведённая к стороне a (десятичное число).

Возвращаемое значение:
- Десятичное число, посчитанное по формуле в зависимости от вызываемой функции.

Пример:
```python
def area(a, h): 
    return a * h / 2 


def perimeter(a, b, c):
    return a + b + c 

print(area(4, 7))
print(perimeter(5, 7, 9))
```

Результат:
```
14.0
21
```
