# geometric_lib
## Описание
`geometric_lib` — библиотека для вычисления площади и периметра простых геометрических фигур: круга, прямоугольника, квадрата и треугольника.

## Вызов функций
Каждый модуль содержит две функции:
- `area()` - вычисление площади
- `perimeter()` - вычисление перемитра

Функции вызываются через интерактивный режим интерпретатора. Для перехода в интерактивный режим можно воспользоваться одной из следующих команд:  
* `python -i script.py`  
* `python3 -i script.py`  
**script.py** - имя вашего файла

Далее функции вызываются следующим образом:  
* `area(a)`   
* `perimeter(a, b)`  
**area** и **perimeter** — названия функций  
**a** и **b** - аргументы функций *(в некоторых функциях требуется только 1 аргумент, а в некоторых — 2)*

Для выхода из интерактивного режима воспользуйтесь командой `exit`.

## Circle
В модуле `Circle` заложены функции для вычисления площади и периметра **круга**. Здесь функции `area()` и `perimeter()` принимают на вход только один аргумент r — радиус (десятичное число).

Используемые формулы:
- **S = πr²** - вычисление площади
- **P = 2πr** - вычисление периметра  
*Примечание: π = 3.141592653589793*

Команды для входа в интерактивный режим:
* `python -i circle.py`  
* `python3 -i circle.py`  

Примеры использования функций:
* Ввод: `area(6)` --> Вывод: `113.09733552923255`
* Ввод: `perimeter(10)` --> Вывод: `62.83185307179586`

Для выхода из интерактивного режима воспользуйтесь командой `exit`.


## Rectangle
В модуле `Rectangle` заложены функции для вычисления площади и периметра **прямоугольника**. Здесь функции `area()` и `perimeter()` принимают на вход ровно два аргумента: a — длина, b — ширина (a и b — десятичные числа).

Используемые формулы:
- **S = ab** - вычисление площади
- **P = 2a + 2b** - вычисление периметра  

Команды для входа в интерактивный режим:
* `python -i rectangle.py`  
* `python3 -i rectangle.py`  

Примеры использования функций:
* Ввод: `area(3, 10)` --> Вывод: `30`
* Ввод: `perimeter(4, 7)` --> Вывод: `22`

Для выхода из интерактивного режима воспользуйтесь командой `exit`.

## Triangle
В модуле `Triangle` заложены функции для вычисления площади и периметра **треугольника**. Функции `area()` принимает на вход ровно два аргумента: a — длина основания, h — высота, проведённая к основанию (a, h - десятичные числа). Функция `perimeter()` принимают на вход ровно три аргумента: a, b и c — длины сторон (a, b и c — десятичные числа).

Используемые формулы:
- **S = ah / 2** - вычисление площади
- **P = P = a + b + c** - вычисление периметра  

Команды для входа в интерактивный режим:
* `python -i triangle.py`  
* `python3 -i triangle.py`  

Примеры использования функций:
* Ввод: `area(4, 7)` --> Вывод: `14.0`
* Ввод: `perimeter(5, 7, 9)` --> Вывод: `21`

Для выхода из интерактивного режима воспользуйтесь командой `exit`.
