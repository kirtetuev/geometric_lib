# geometric_lib
## Описание
`geometric_lib` — библиотека для вычисления площади и периметра простых геометрических фигур: круга, прямоугольника, квадрата и треугольника.

## Circle
Данный модуль вычисляет площадь и периметр **круга**.
```python
import math

def area(r):
    return math.pi * r * r


def perimeter(r):
    return 2 * math.pi * r
```

### Area Circle
```python
area(r)
```  
Функция возвращает площадь **круга** по формуле **S = πr²**.  

Параметры:
- **r** - радиус круга (десятичное число).

Возвращаемое значение:
- Десятичное число, посчитанное по формуле **S = πr²**.

Примечание:
- π = 3.141592653589793.

Пример:
```python
print(area(6))
```

Результат:
```
113.09733552923255
```

### Perimeter Circle
```python
perimeter(r)
```  
Функция возвращает периметр **круга** по формуле **P = 2πr**.  

Параметры:
- **r** - радиус круга (десятичное число).

Возвращаемое значение:
- Десятичное число, посчитанное по формуле **P = 2πr**.

Примечание:
- π = 3.141592653589793.

Пример:
```python
print(perimeter(10))
```

Результат:
```
62.83185307179586
```



## Rectangle
Данный модуль вычисляет площадь и периметр **прямоугольника**.
```python
def area(a, b):
    return a * b 


def perimeter(a, b):
    return (a + b) * 2
```

### Area Rectangle
```python
area(a, b)
```  
Функция возвращает площадь **прямоугольника** по формуле **S = ab**.  

Параметры:
- **a** - длина квадрата (десятичное число).
- **b** - ширина квадрата (десятичное число).


Возвращаемое значение:
- Десятичное число, посчитанное по формуле **S = ab**.


Пример:
```python
print(area(3, 10))
```

Результат:
```
30
```

### Perimeter Rectangle
```python
perimeter(a, b)
```  
Функция возвращает периметр **прямоугольника** по формуле **P = 2a + 2b**.  

Параметры:
- **a** - длина прямоугольника (десятичное число).
- **b** - ширина прямоугольника (десятичное число).

Возвращаемое значение:
- Десятичное число, посчитанное по формуле **P = 2a + 2b**.

Пример:
```python
print(perimeter(4, 7))
```

Результат:
```
22
```

## Triangle
Данный модуль вычисляет площадь и периметр **треугольника**.
```python
def area(a, h): 
    return a * h / 2 


def perimeter(a, b, c):
    return a + b + c 
```

### Area Triangle
```python
area(a, h)
```  
Функция возвращает площадь **треугольника** по формуле **S = ah / 2**.  

Параметры:
- **a** - длина стороны треугольника (десятичное число).
- **h** - длина высоты, проведённой к стороне **a** (десятичное число).


Возвращаемое значение:
- Десятичное число, посчитанное по формуле **S = ah / 2**.


Пример:
```python
print(area(4, 7))
```

Результат:
```
14.0
```

### Perimeter Triangle
```python
perimeter(a, b, c)
```  
Функция возвращает периметр **треугольника** по формуле **P = a + b + c**.  

Параметры:
- **a** - длина первой стороны треугольника (десятичное число).
- **b** - длина второй стороны треугольника (десятичное число).
- **c** - длина третьей стороны треугольника (десятичное число).

Возвращаемое значение:
- Десятичное число, посчитанное по формуле **P = a + b + c**.

Пример:
```python
print(perimeter(5, 7, 9))
```

Результат:
```
21
```
